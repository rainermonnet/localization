## 🔧 Bild in Shopify hochladen – Anleitung

### Manuell im Admin (ein Produkt):
1. Shopify Admin → Produkte → Produkt öffnen
2. Im Bereich "Medien" auf "Dateien hinzufügen" klicken
3. Bild hochladen oder URL einfügen
4. Speichern

### Per API (Bulk-Upload) – siehe `shopify-bilder-upload.py`
